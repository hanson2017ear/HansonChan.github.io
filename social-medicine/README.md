# 社会医学课程练习

可以填写课堂的WHOQOL-100问卷，计算中国糖尿病风险评分、记录自己的健康危险因素，也可以重做HRA和QALY课堂例题。支持手机和电脑，下载后可离线使用。

**[在线使用](https://hanson2017ear.github.io/HansonChan.github.io/social-medicine/)** · [生命质量评分](https://hanson2017ear.github.io/HansonChan.github.io/social-medicine/#whoqol) · [健康危险因素评价](https://hanson2017ear.github.io/HansonChan.github.io/social-medicine/#hra) · [QALY](https://hanson2017ear.github.io/HansonChan.github.io/social-medicine/#qaly)

## WHOQOL-100 与课堂评分

- 打开时是一份空白问卷，100道题都能看到完整题干与各自的五个选项。按25个方面分组，每组4题，可以前后翻组，也可以直接选择题组或查找漏答。
- 题目及选项据课堂问卷第1—7页逐题整理，保留 `F1.1—F24.4`、`G1—G4` 代码。满意程度、频率、困难程度等选项按原题呈现，不统一替换成同一套“1—5”。
- 未填完也能点“保存答卷”，下载含100个条目的CSV。留空的题仍为空白，下次导入即可继续；替换个人答卷或重新填写前会提示确认。
- 已有纸质答案，可直接导入CSV，使用未转向的A—E或1—5。不要把其他译本的第1—100题序直接套入。
- 自动处理课堂评分表的30个反向条目；逐方面展示原始答案、反向过程、4—20分及0—100转换分。
- 保留六领域分布、G1—G4的原始答案和转换分，另列**课堂五领域均分**。
- 可将当前答卷设为对照，再录入或导入同一对象的复评数据。每个领域显示两次分数与变化。
- 可下载空白CSV模板，也可导出结果、逐题题目与所选答案、计分过程和笔记。格式错误、未知条目或重复条目不会覆盖原有输入。
- 采用完整作答模式：缺项先补齐，不用0替代，不实现缺失值插补。

课堂正向题A—E计1—5，反向题计5—1。每个方面的4题转向后相加：

`方面标准分 = (转向后方面分 − 4) / 16 × 100`

领域分为该领域各方面标准分的平均值。原始领域分范围为4—20；图表统一用0—100分表示。

`课堂五领域均分 = (生理 + 心理 + 独立性 + 社会关系 + 环境) / 5`

课堂汇总分排除精神、宗教与个人信念领域和G1—G4，属于本课程评分说明的约定，**不称为WHO推荐的统一总分**。应同时解释六领域及具体方面，不设自编诊断界值，也不将领域分当成QALY效用。

课堂30个反向条目：F1.1—F1.4、F2.2、F2.4、F3.2、F3.4、F7.2、F7.3、F8.1—F8.4、F9.3、F9.4、F10.2、F10.4、F11.1—F11.4、F13.1、F15.4、F16.3、F18.2、F18.4、F22.2、F23.2、F23.4。

这与WHO网站所提供手册中先处理方面内部条目、再对F1、F8、F11整体转向的公式，在完整作答时等价。两种流程不能叠加，否则会重复反向。

## 健康危险因素评价

### 个人风险评分

个人填写区新增**中国糖尿病风险评分（NCDRS）**。依据Zhou等原研究表2，将6项指标转换为分值后求和，显示原始资料、对应分组、逐项分值、总分、25分切点及解释，并可下载单独的风险评分表CSV。所有计算仍在浏览器内进行。

`总分＝年龄分＋性别分＋BMI分＋腰围分＋收缩压分＋一级亲属糖尿病史分`

- 评分针对中国20—74岁、尚未确诊糖尿病的人群，筛查未诊断的2型糖尿病。总分0—51；≥25提示应进一步筛查。分值**不是患病概率，不是全病种总风险**；低于25也不能排除糖尿病。
- 本页仅对“一般成年人”评分；孕产期、需要个别方案、已经确诊糖尿病或年龄不符时不外推。未选适用情况或未回答确诊情况时不出总分。
- 缺少6项指标或相应必要资料时，列出待补项目，可点击回到输入处；不为缺项补0。血压需记录测量方式，本页不把单次家庭读数用于正式总分。
- BMI按未四舍五入的值判组；腰围按原表男、女两套界点计分。糖尿病家族史仅指父母、兄弟姐妹或子女，不用原表单中“心血管病或糖尿病”的笼统回答替代。
- 总分图的横轴是0—51**分**，标出25分筛查切点。51是评分上限，不是健康满分。分数与下方8项习惯参照不混合，也不换算成百分比。
- “保留本次”后，可比较两次资料完整、适用且来源标记一致的评分。分数变化不解释为患病概率降低，也不能证明干预效果。
- 原有个人资料JSON仍可导入；新增的确诊情况与糖尿病家族史留空，待补后再计分。示例是一份虚构的21岁男性资料，计11分，不来自用户健康记录。
- 另提供[国家心血管病中心China-PAR官方工具](https://www.cvdrisk.com.cn/ASCVD/Eval)入口，用于有血脂等必要资料者进一步评估。外部工具由填写者主动打开，本页不自动传送个人资料；不在本地复制未核准的心血管模型参数。

计分权重：

| 指标 | 分组与分值 |
| --- | --- |
| 年龄（岁） | 20—24:0；25—34:4；35—39:8；40—44:11；45—49:12；50—54:13；55—59:15；60—64:16；65—74:18 |
| 性别 | 女0；男2 |
| BMI（kg/m²） | <22:0；22—<24:1；24—<30:3；≥30:5 |
| 腰围（cm，男/女） | <75/<70:0；75—<80/70—<75:3；80—<85/75—<80:5；85—<90/80—<85:7；90—<95/85—<90:8；≥95/≥90:10 |
| 收缩压（mmHg） | <110:0；110—<120:1；120—<130:3；130—<140:6；140—<150:7；150—<160:8；≥160:10 |
| 一级亲属糖尿病史 | 无0；有6 |

来源：[Zhou X, et al. *Diabetes Care*. 2013;36:3944–3952，表2](https://doi.org/10.2337/dc13-0593)；[CDC文献库原文及评分表](https://stacks.cdc.gov/view/cdc/28193/cdc_28193_DS1.pdf)；[中国2型糖尿病防治指南（2020年版），表5及筛查说明](https://gpedu.yiigle.com/uploads/guide_html/中国2型糖尿病防治指南（2020年版）%20-%20中华糖尿病杂志.html)。

### 生活习惯与个人评价表

默认打开空白的个人填写区，课堂综合风险计算放在另一个按钮下。风险评分以外，还可以填写运动、睡眠、饮食、吸烟饮酒，以及压力、社会支持和其他体检值。填完一部分也能看已有项目的参照结果，不知道的数据留空。

- 计算BMI和每周中等强度等效活动量：`中等强度分钟＋2×较大强度分钟`。BMI按中国成人18.5、24、28界点解释；腰围另列，不合并成“总风险”。
- 逐项核对有氧活动、力量训练、睡眠、蔬果、盐、吸烟、二手烟、饮酒8项参照。分别显示“达到参照”“可再调整”“待补资料”；缺项不补0，不当成已经达到参照。
- 8项完成数是**日常习惯的对照记录，不是经过验证的风险量表总分，不代表患病概率**。各项不具有同等的临床权重，不计算自编的健康百分数，也不声称是课堂历史HRA算法的个人版。
- 统一习惯参照限18—64岁一般成年人；年龄未确认、未成年人、65岁以上、孕产期或需要个别方案者保留填写内容，不套用这组参照或BMI分类。
- 血压区分诊室、单次家庭读数与连续5—7天家庭平均值。体检记录不计入8项，不根据一次血糖或单项总胆固醇判断健康或调整药物。
- 可保存为JSON后导入继续；未填完也能保存，临时保留的对照同时写入文件。格式、选项或数值有误时，不覆盖当前资料；替换及清空前先确认。
- “保留本次”后修改资料，可以比较两次**都有记录**的习惯。新增资料不算改善；体重下降也不自动解释为更健康。
- 模拟资料单独标记；混合模拟和自行填写的数据时不计算改善。示例不来自个人健康记录。
- 可记录具体行动与复评日期，导出原始资料、逐项依据、计算过程、前后对照和应用笔记。复评日期是记录，不会自动发提醒。
- 点击“查看个人评价表”，可直接查看按本人资料生成的完整表格：生活方式9项（8项习惯参照及久坐记录）、体格与体检5项、家庭与社会环境3项，共17项。列出本次资料、参照、评价、可采取的行动和来源网址；年龄、适用情况等另作表头说明。
- 结果区显示8项习惯的构成环形图及每周有氧活动量图。图表与表格同步更新；未知数据保留，体检值不混入习惯项数。保留对照后，可在同一活动量坐标下查看上次记录。
- 评价表支持CSV下载及打印/保存为PDF。CSV包含记录日期、年龄、适用情况、模拟资料标记和来源；没有公开分享个人结果的功能。其他人从同一网址打开的是自己的空白表单。

个人习惯参照的原网址：

1. [WHO身体活动与久坐指南（2020）](https://www.who.int/publications/i/item/9789240015128)：每周至少150分钟中等强度等效活动、至少2天力量训练。
2. [WHO健康饮食](https://www.who.int/en/news-room/fact-sheets/detail/healthy-diet)：蔬菜水果合计至少400 g/天，成人食盐少于5 g/天。
3. [中华医学会《健康睡眠四要素》（2024）](https://www.cma.org.cn/art/2024/5/13/art_4584_56543.html)：18—64岁通常7—9小时，结合睡眠质量解释。
4. [WHO烟草与尼古丁](https://www.who.int/news-room/fact-sheets/detail/tobacco)、[WHO酒精](https://www.who.int/news-room/fact-sheets/detail/alcohol)：避免烟草、二手烟及酒精暴露；不把“最近一周没有”解释为不存在长期风险。
5. [国家卫生健康委体重、腰围说明（2025）](https://www.nhc.gov.cn/xcs/c100122/202503/27b26d397f4941ff8ff3846ef40026ee.shtml)。
6. [国家卫生健康委血压参照说明](https://www.nhc.gov.cn/jkj/c100063/202009/b6a4c154c6574ed6814c15010c8b4b94.shtml)：诊室140/90 mmHg、连续5—7天家庭平均135/85 mmHg，就诊核对与确诊条件另行解释。

### 课堂例题

复现课堂补充表12-1至12-3中41岁男性的12项死因例题，保留各因素分数、组合分数、存在死亡危险、改善前后差和年龄参照。

- 可载入完整改善方案、只改变体力活动，或保持所有因素不变。
- 每个死因均可展开核对，并修改当前及改善后危险分数。
- 测量值转换使用课堂表12-2的男性40—44岁组，提供血压、胆固醇及分类因素查询。连续指标只在相邻参照点间内插，不外推。
- 转换结果须主动点击才会用于冠心病当前项，不会自动覆盖例题或改善后值。
- 年龄演示仅包含与41岁男性例题相关的参照区段，用于比较风险水平，不能根据年龄差预测寿命。

`R = Σ(r > 1 时的 r − 1) + Π(r ≤ 1 时的 r)`

`存在死亡危险 D = 基准死亡率 M × R`

默认先把R保留2位再乘M，与课堂表格一致；可取消勾选比较完整精度。总量用各行未进一步四舍五入的D求和，各率值单位均为每10万人。

| 完整例题核对值 | 数值 |
| --- | ---: |
| 当前总危险 | 7167.45 /10万 |
| 改善后总危险 | 3430.35 /10万 |
| 减少量 | 3737.10 /10万 |
| 下降比例 | 52.1399%，保留一位为52.1% |

### 课堂补充表与第五版印刷值的差异

按课堂补充表核对：

1. 自杀改善后为 `264×1.5=396`；第五版表11-1对应格印为369。
2. 肺炎改善后 `R=1`、`D=111`；第五版对应R格印为0.1而D列为111，课堂补充表已列R为1。
3. 下降比例按总量相除，不把已四舍五入的分项百分比相加。课堂补充表为52.1%，第五版分项相加列52.2%。
4. 胆固醇192 mg/dl的独立内插练习为0.65；综合例题仍按表中0.6保留，两处课堂数据不自动混用。

这是教材的历史教学模型，其系数、筛查与干预设置不作为现行医疗建议，也不用于当前个人临床风险预测。

## QALY 与应用记录

`QALY = Σ(持续年数 × 对应健康效用权重)`

课堂例题 `65.2×1 + 4.5×0.59 + 1.9×0.34 = 68.501 QALY`，课件约为68.5；未调整年数为71.6年。

保留EQ-5D-3L健康状态编码与VAS记录练习，不套用未指定的价值集。状态编码、VAS、效用指数不同，不能以等级相加、VAS/100或WHOQOL领域分替代效用值。

三个模块都有笔记栏，方便记下自己的发现和下一步打算。可连同计分过程、结果及来源一起导出，也可打印当前模块。

## 模拟数据与隐私

WHOQOL默认是空白问卷。“课堂示例与空白CSV”内可以另行查看模拟答卷和前后对照。示例不来自个人答卷或研究样本，不能写成真实调查或干预结果。

计算在当前浏览器完成，没有后端、账号、答卷上传、浏览记录分析或自动保存。刷新会清空当前答案、临时对照与笔记，离开前请保存答卷或个人资料，并导出需要保留的结果。保存下来的个人文件也含健康信息，请自行保管；公开仓库不包含这些文件、课堂答卷照片、个人健康记录或教材扫描件。

## 离线使用和验证

将本目录全部下载，双击 `index.html` 即可。CSS、JavaScript和二维码都在同一目录，不依赖外部CDN。也可直接放入GitHub Pages静态发布目录。

- `index.html`：页面结构与来源；`style.css`：桌面、手机、打印版式。
- `app.js`：表单、图表及导入导出；`course-data.js`：条目编码、模拟答卷和课堂参数。
- `personal-hra.js`：个人资料、NCDRS风险评分及分项CSV、逐项习惯参照、保存和前后对照；可独立测试计算部分。
- `whoqol-questions.js`：100道课堂题目、每题的选项及原表页码，不含手写答案。
- `calc.js`：独立计算函数；`test.cjs`：无需第三方依赖的核对测试。
- `qr-*.svg`：三个模块的线上入口二维码。

运行 `node test.cjs`。测试包含100道题及其选项、原表页码分布、30反向条目、首尾分值、六领域与课堂汇总、部分作答CSV、非法输入、12项死因及情景比较、内插和QALY例题，以及个人表单的边界、缺项、适用范围、BMI和运动换算、血压测量方式、JSON校验。浏览器另行检查填写、保存与恢复、替换前确认、前后对照、导出、打印和390像素手机显示。资料与结果的真实文件下载也须在上线检查中核对。

NCDRS测试覆盖全部年龄、BMI、男女腰围及收缩压的分组边界，0、24、25、51分、适用条件、缺项、两种家族史的区分、旧JSON兼容及评分表CSV。新版仍需另行检查线上表单、导出、旧资料恢复和手机显示。

课程学习工具，非WHO、EuroQol或China-PAR官方软件。使用其他版本量表时，应重新核对条目代码及该版本规则。
