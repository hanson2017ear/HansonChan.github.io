# 社会医学课程练习

可以直接填写课堂的WHOQOL-100问卷，也可以重做健康危险因素评价和QALY例题。支持手机和电脑，下载后可离线使用。

**[在线使用](https://hanson2017ear.github.io/HansonChan.github.io/social-medicine/)** · [生命质量评分](https://hanson2017ear.github.io/HansonChan.github.io/social-medicine/#whoqol) · [健康危险因素评价](https://hanson2017ear.github.io/HansonChan.github.io/social-medicine/#hra) · [QALY](https://hanson2017ear.github.io/HansonChan.github.io/social-medicine/#qaly)

## WHOQOL-100 与课堂评分

- 打开时是一份空白问卷，100道题都能看到完整题干与各自的五个选项。按25个方面分组，每组4题，可以前后翻组，也可以直接选择题组或查找漏答。
- 题目及选项据课堂问卷第1—7页逐题整理，保留 `F1.1—F24.4`、`G1—G4` 代码。满意程度、频率、困难程度等选项按原题呈现，不统一替换成同一套“1—5”。
- 未填完也能点“保存答卷”，下载含100个条目的CSV。留空的题仍为空白，下次导入即可继续；替换个人答卷或重新填写前会提示确认。
- 已有纸质答案，可直接导入CSV，使用未转向的A—E或1—5。不要把其他译本的第1—100题序直接套入。
- 自动处理课堂评分表的30个反向条目；逐方面展示原始答案、反向过程、4—20分及0—100转换分。
- 保留六领域分布、G1—G4的原始答案和转换分，另列**课堂五领域均分**。
- 可将当前答卷设为对照，再录入或导入同一对象的复评数据。每个领域显示两次分数与变化。
- 可下载空白CSV模板，也可导出结果、逐题题目与所选答案、计分过程和笔记。格式错误、未知条目或重复条目不会覆盖原有输入。
- 采用完整作答模式：缺项先补齐，不用0替代，不实现缺失值插补。

课堂正向题A—E计1—5，反向题计5—1。每个方面的4题转向后相加：

`方面标准分 = (转向后方面分 − 4) / 16 × 100`

领域分为该领域各方面标准分的平均值。原始领域分范围为4—20；图表统一用0—100分表示。

`课堂五领域均分 = (生理 + 心理 + 独立性 + 社会关系 + 环境) / 5`

课堂汇总分排除精神、宗教与个人信念领域和G1—G4，属于本课程评分说明的约定，**不称为WHO推荐的统一总分**。应同时解释六领域及具体方面，不设自编诊断界值，也不将领域分当成QALY效用。

课堂30个反向条目：F1.1—F1.4、F2.2、F2.4、F3.2、F3.4、F7.2、F7.3、F8.1—F8.4、F9.3、F9.4、F10.2、F10.4、F11.1—F11.4、F13.1、F15.4、F16.3、F18.2、F18.4、F22.2、F23.2、F23.4。

这与WHO网站所提供手册中先处理方面内部条目、再对F1、F8、F11整体转向的公式，在完整作答时等价。两种流程不能叠加，否则会重复反向。

## 健康危险因素评价

复现课堂补充表12-1至12-3中41岁男性的12项死因例题，保留各因素分数、组合分数、存在死亡危险、改善前后差和年龄参照。

- 可载入完整改善方案、只改变体力活动，或保持所有因素不变。
- 每个死因均可展开核对，并修改当前及改善后危险分数。
- 测量值转换使用课堂表12-2的男性40—44岁组，提供血压、胆固醇及分类因素查询。连续指标只在相邻参照点间内插，不外推。
- 转换结果须主动点击才会用于冠心病当前项，不会自动覆盖例题或改善后值。
- 年龄演示仅包含与41岁男性例题相关的参照区段，用于比较风险水平，不能根据年龄差预测寿命。

`R = Σ(r > 1 时的 r − 1) + Π(r ≤ 1 时的 r)`

`存在死亡危险 D = 基准死亡率 M × R`

默认先把R保留2位再乘M，与课堂表格一致；可取消勾选比较完整精度。总量用各行未进一步四舍五入的D求和，各率值单位均为每10万人。

| 完整例题核对值 | 数值 |
| --- | ---: |
| 当前总危险 | 7167.45 /10万 |
| 改善后总危险 | 3430.35 /10万 |
| 减少量 | 3737.10 /10万 |
| 下降比例 | 52.1399%，保留一位为52.1% |

### 课堂补充表与第五版印刷值的差异

按课堂补充表核对：

1. 自杀改善后为 `264×1.5=396`；第五版表11-1对应格印为369。
2. 肺炎改善后 `R=1`、`D=111`；第五版对应R格印为0.1而D列为111，课堂补充表已列R为1。
3. 下降比例按总量相除，不把已四舍五入的分项百分比相加。课堂补充表为52.1%，第五版分项相加列52.2%。
4. 胆固醇192 mg/dl的独立内插练习为0.65；综合例题仍按表中0.6保留，两处课堂数据不自动混用。

这是教材的历史教学模型，其系数、筛查与干预设置不作为现行医疗建议，也不用于当前个人临床风险预测。

## QALY 与应用记录

`QALY = Σ(持续年数 × 对应健康效用权重)`

课堂例题 `65.2×1 + 4.5×0.59 + 1.9×0.34 = 68.501 QALY`，课件约为68.5；未调整年数为71.6年。

保留EQ-5D-3L健康状态编码与VAS记录练习，不套用未指定的价值集。状态编码、VAS、效用指数不同，不能以等级相加、VAS/100或WHOQOL领域分替代效用值。

三个模块都有笔记栏，方便记下自己的发现和下一步打算。可连同计分过程、结果及来源一起导出，也可打印当前模块。

## 模拟数据与隐私

WHOQOL默认是空白问卷。“课堂示例与空白CSV”内可以另行查看模拟答卷和前后对照。示例不来自个人答卷或研究样本，不能写成真实调查或干预结果。

计算在当前浏览器完成，没有后端、账号、答卷上传、浏览记录分析或自动保存。刷新会清空当前答案、临时对照与笔记，离开前请保存答卷并导出需要保留的结果。公开仓库不包含课堂答卷照片、个人健康记录或教材扫描件。

## 离线使用和验证

将本目录全部下载，双击 `index.html` 即可。CSS、JavaScript和二维码都在同一目录，不依赖外部CDN。也可直接放入GitHub Pages静态发布目录。

- `index.html`：页面结构与来源；`style.css`：桌面、手机、打印版式。
- `app.js`：表单、图表及导入导出；`course-data.js`：条目编码、模拟答卷和课堂参数。
- `whoqol-questions.js`：100道课堂题目、每题的选项及原表页码，不含手写答案。
- `calc.js`：独立计算函数；`test.cjs`：无需第三方依赖的核对测试。
- `qr-*.svg`：三个模块的线上入口二维码。

运行 `node test.cjs`。测试包含100道题及其选项、原表页码分布、30反向条目、首尾分值、六领域与课堂汇总、部分作答CSV、非法输入、12项死因及情景比较、内插和QALY例题。另以独立浏览器检查了100道题的点选、前后翻组、漏答定位、替换前确认、保存与导入恢复、前后对照、导出内容、打印、键盘切换及390像素手机宽度。受沙箱限制，本次保存检查核对的是生成的文件内容，未在操作系统中实际下载文件。

课程学习工具，非WHO或EuroQol官方软件。使用其他版本量表时，应重新核对条目代码及该版本规则。
