# 社会医学课程练习

可以填写课堂WHOQOL-100问卷，按表12-1、12-2、12-3完成健康危险因素评价，或重做QALY课堂例题。支持手机和电脑，下载后可离线使用。

## WHOQOL-100 与课堂评分

- 打开时是一份空白问卷，100道题都能看到完整题干与各自的五个选项。按25个方面分组，每组4题，可以前后翻组，也可以直接选择题组或查找漏答。
- 题目及选项据课堂问卷第1—7页逐题整理，保留 `F1.1—F24.4`、`G1—G4` 代码。满意程度、频率、困难程度等选项按原题呈现，不统一替换成同一套“1—5”。
- 未填完也能点“保存答卷”，下载含100个条目的CSV。留空的题仍为空白，下次导入即可继续；替换个人答卷或重新填写前会提示确认。
- 已有纸质答案，可直接导入CSV，使用未转向的A—E或1—5。不要把其他译本的第1—100题序直接套入。
- 自动处理课堂评分表的30个反向条目；逐方面展示原始答案、反向过程、4—20分及0—100转换分。
- 保留六领域分布、G1—G4的原始答案和转换分，另列**课堂五领域均分**。
- 可将当前答卷设为对照，再录入或导入同一对象的复评数据。每个领域显示两次分数与变化。
- 可下载空白CSV模板，也可导出结果、逐题题目与所选答案、计分过程和笔记。格式错误、未知条目或重复条目不会覆盖原有输入。
- 采用完整作答模式：缺项先补齐，不用0替代，不实现缺失值插补。

课堂正向题A—E计1—5，反向题计5—1。每个方面的4题转向后相加：

`方面标准分 = (转向后方面分 − 4) / 16 × 100`

领域分为该领域各方面标准分的平均值。原始领域分范围为4—20；图表统一用0—100分表示。

`课堂五领域均分 = (生理 + 心理 + 独立性 + 社会关系 + 环境) / 5`

课堂汇总分排除精神、宗教与个人信念领域和G1—G4，属于本课程评分说明的约定，**不称为WHO推荐的统一总分**。应同时解释六领域及具体方面，不设自编诊断界值，也不将领域分当成QALY效用。

课堂30个反向条目：F1.1—F1.4、F2.2、F2.4、F3.2、F3.4、F7.2、F7.3、F8.1—F8.4、F9.3、F9.4、F10.2、F10.4、F11.1—F11.4、F13.1、F15.4、F16.3、F18.2、F18.4、F22.2、F23.2、F23.4。

这与WHO网站所提供手册中先处理方面内部条目、再对F1、F8、F11整体转向的公式，在完整作答时等价。两种流程不能叠加，否则会重复反向。

## 健康危险因素评价：按课堂三表重做

本版按“健康风险”资料夹的表12-1、12-2、12-3及课程课件第163—174页整理。填写原始变量后，计算表12-1第6—13列，再查评价年龄和增长年龄。

### 从变量到结果

1. 填写血压、胆固醇、糖尿病史、体力活动、家族史、吸烟、体重、饮酒、驾车里程、安全带、抑郁及其他疾病相关变量。共25个变量输入，覆盖12项死因的33个因素记录。
2. 冠心病使用表12-2转换分数，连续指标可在相邻点间内插。血压选择收缩压或舒张压作为**一项**因素，支持表中mmHg、kPa各自列示的参照点，不将两项血压分数重复加入。
3. 每个死因按其自身的r值计算组合危险分数R和存在死亡危险D。相同变量在不同死因中的分数不同，不能把冠心病转换表复制给其他死因。
4. 改善后留空表示保持当前。可逐项填写改善设定，也可套用课件第174页的4项改变，或把改善后全部恢复为保持当前。
5. 生成12项死因汇总、改善前后对照图和完整13列表12-1。图旁用箭头标明每项上升或下降了多少：变化百分比以该项当前D为分母；表12-1第13列仍按原总危险作分母。无变化、当前值为0和资料缺项分别处理。CSV包含原表13列、分数来源和计算设置；同一死因的组值只在首行列示。
6. 将12项D相加，按实际年龄末位在表12-3选列，再按相邻危险值内插，显示评价年龄和增长年龄以及具体查表过程。

### 按课堂给定值复算，或按转换表内插

页面明确区分两种口径：

- **优先沿用表12-1给定值**：胆固醇192 mg/dl用0.6，超重30%用1.3，完整算例复现原课堂表。其他连续测量值如不在综合表中，仍按已有表12-2转换；不会虚构新系数。
- **冠心病按表12-2内插**：192 mg/dl得到0.65；超重30%在15%与50%之间内插，得到1.214286。它们与综合表的给定值不同，结果也会不同。其他死因仍使用各自已有的分数。

“载入课堂完整算例”使用给定值口径。两种口径、R保留两位/完整精度的设置，都写入保存文件和导出结果，不能默默混用。

### 参数范围与缺失处理

- 表12-1、12-2目前提供男性40—44岁参数。年龄可以填写以核对适用性；其他年龄或女性不产生沿用这组男性参数的危险结果。改变到其他人群，需要补齐相应死亡基准率和转换表。
- 心脏杂音、风湿热等有无类项目可直接选择“有”或“无”；结核相关X线检查可选“阳性”或“阴性”。教材未提供相应条件的系数时，保留填写并列为待补项。
- 不知道的当前变量保留空白；未知不计0。未完成项可以查看，12项未全部完成时不显示残缺后的“总危险”或查表年龄。
- 表12-2只有冠心病转换表。其他死因在表12-1中通常只有给定条件和分数；改到资料未涵盖的条件时，会明确列出待补系数。不能自行认定“无”就一定是1，或假设各死因通用同一分数。
- 可对各死因、各因素补充当前/改善后的r值，但必须同时填写表号、页码或原网址。未写来源时不采用；修改相关原始变量会清除其手工系数，防止旧分数残留。
- 年龄查表录入男性列1600—61640的单调区段，基础年龄24—70岁。实际年龄末位0/5、1/6、2/7、3/8、4/9分别选相应列；超出危险区段不外推。原表低龄行有重复或非单调率值，不强行反求唯一年龄。
- 评价年龄与增长年龄是风险对应年龄，不是预计寿命；其差值不作为延寿年数。

### 保存、导出与旧版记录

- 打开时为空白变量表，可随时载入题目算例。保存JSON包含原始变量、改善设定、参数选择、给定值/内插口径、资料标记及手工系数来源。导入前校验；替换已有资料前提示保存。
- 支持导出完整表12-1 CSV、带计算过程的文字记录、浏览器打印。表格、图与年龄随资料更新；非法输入会清除旧计算结果。
- 提供同实现的单页文件 `健康危险因素评价_课堂计算版.html`。可打开综合课程工具，也可单独使用课堂计算器。
- 以前保存的生活方式资料可在 `legacy.html#hra` 打开；本页需另外填写表12-1对应的变量。

### 课堂资料核对

来源为用户提供的健康风险补充表12-1（第150—151页）、12-2（第153页）、12-3（第154页）和课程课件第163—174页。李鲁《社会医学》第5版对应第11章、表11-1至11-3，注意两套资料的表号与页码不同。

自杀改善后采用补充表的396＝264×1.5；肺炎改善后R＝1、D＝111；下降比例按总量相除，得52.1%，不将已四舍五入的各项百分比相加。这些课堂历史系数及“每年直肠镜检查”等设定不作为现行个人医疗或筛查建议。


## QALY 与应用记录

`QALY = Σ(持续年数 × 对应健康效用权重)`

课堂例题 `65.2×1 + 4.5×0.59 + 1.9×0.34 = 68.501 QALY`，课件约为68.5；未调整年数为71.6年。

保留EQ-5D-3L健康状态编码与VAS记录练习，不套用未指定的价值集。状态编码、VAS、效用指数不同，不能以等级相加、VAS/100或WHOQOL领域分替代效用值。

三个模块都有笔记栏，方便记下自己的发现和下一步打算。可连同计分过程、结果及来源一起导出，也可打印当前模块。

## 模拟数据与隐私

WHOQOL默认是空白问卷。“课堂示例与空白CSV”内可以另行查看模拟答卷和前后对照。示例不来自个人答卷或研究样本，不能写成真实调查或干预结果。

计算在当前浏览器完成，没有后端、账号、答卷上传、浏览记录分析或自动保存。刷新会清空当前答案、临时对照与笔记，离开前请保存答卷或个人资料，并导出需要保留的结果。保存下来的个人文件也含健康信息，请自行保管；公开仓库不包含这些文件、课堂答卷照片、个人健康记录或教材扫描件。

## 离线使用和验证

将本目录全部下载，双击 `index.html` 即可。CSS、JavaScript和二维码都在同一目录，不依赖外部CDN。也可直接放入GitHub Pages静态发布目录。

- `index.html`：页面结构与来源；`style.css`：桌面、手机、打印版式。
- `app.js`：表单、图表及导入导出；`course-data.js`：条目编码、模拟答卷和课堂参数。
- `hra-lesson.js`：课堂变量输入、死因分数转换、13列表12-1、年龄查表与资料保存。
- `hra-lesson-test.cjs`：12项死因、33项分数、两种转换口径、年龄列、缺失与导出的核对。
- `legacy.html`、`legacy-app.js`、`personal-hra.js`：旧版记录页，仅供取回此前的生活方式资料。
- `whoqol-questions.js`：100道课堂题目、每题的选项及原表页码，不含手写答案。
- `calc.js`：独立计算函数；`test.cjs`：无需第三方依赖的核对测试。
- `qr-*.svg`：三个模块的线上入口二维码。

运行 `node test.cjs`。测试包含100道题及其选项、原表页码分布、30反向条目、首尾分值、六领域与课堂汇总、部分作答CSV、非法输入、12项死因及情景比较、内插和QALY例题，以及个人表单的边界、缺项、适用范围、BMI和运动换算、血压测量方式、JSON校验。浏览器另行检查填写、保存与恢复、替换前确认、前后对照、导出、打印和390像素手机显示。资料与结果的真实文件下载也须在上线检查中核对。

运行 `node hra-lesson-test.cjs` 核对课堂三表计算。测试包含全部12项死因的33项因素、两种转换口径、单位及血压选择、改善设定、各年龄列、缺失参数不赋分、手工分数来源、JSON和13列CSV。浏览器另行核对填写与结果更新、导出和手机显示。

课程学习工具，非WHO或EuroQol官方软件。使用其他版本量表时，应重新核对条目代码及该版本规则。
